# NEON BLOCKS

HTML / CSS / JavaScript だけで遊べる、インストール不要のブラウザ版テトリスです。暗いアーケードをイメージしたレスポンシブな UI で、PC のキーボードでもスマートフォンの画面ボタンでもプレイできます。

## 機能

- 7-bag 方式による 7 種類のテトリミノ
- 左右移動、ソフトドロップ、ハードドロップ、回転（簡易ウォールキック）
- ゴーストピースと次のピースのプレビュー
- ライン消去数に応じた得点・レベル・落下速度の上昇
- 一時停止（タブを離れた場合も自動停止）
- ゲームオーバー画面から即座に再スタート
- モバイル向けタッチ操作とレスポンシブレイアウト
- Node.js 標準テストランナーによるゲームロジックのテスト

## 遊び方

```bash
npm start
```

ブラウザで <http://localhost:8000> を開いてください。ビルド工程や依存パッケージはありません。`index.html` を直接開くのではなく、ES Modules を読み込めるローカルサーバー経由での起動を推奨します。

### 操作

| キー | 操作 |
| --- | --- |
| `←` / `→` | 左右に移動 |
| `↓` | ソフトドロップ（1点） |
| `↑` / `X` | 右回転 |
| `Space` | ハードドロップ（1マスにつき2点） |
| `P` / `Esc` | 一時停止 / 再開 |
| `Enter` | タイトル・ゲームオーバー画面から開始 |

ライン消去は 1 / 2 / 3 / 4 ラインでそれぞれ 100 / 300 / 500 / 800 点に現在のレベルを掛けた得点です。10 ライン消すごとにレベルが上がり、落下速度が速くなります。

## テスト

```bash
npm test
```

盤面生成、衝突判定、ライン消去と得点、レベルアップ、ハードドロップ、一時停止、7-bag を検証します。

## ファイル構成

- `index.html` — ゲーム画面とアクセシブルな操作 UI
- `styles.css` — レスポンシブなアーケード風デザイン
- `game.js` — DOM に依存しないゲームロジック
- `script.js` — Canvas 描画、入力、ゲームループ
- `tests/game.test.js` — ゲームロジックのユニットテスト

## 対応環境

ES Modules と Canvas API をサポートする最新の Chrome、Firefox、Safari、Edge を対象としています。
